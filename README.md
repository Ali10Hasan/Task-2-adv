Little Learners Academy - Landing Page

📌 Project Overview

This project is a responsive landing page for a kindergarten website called Little Learners Academy.
It is designed to provide a modern, clean, and user-friendly interface that showcases the school's information, programs, and services.

---

🛠️ Technologies Used

- React (with TypeScript)
- CSS Modules
- Responsive Design (Media Queries)
- Flexbox & CSS Grid

---

🎯 Features

- Fully responsive design for all screen sizes (Desktop, Tablet, Mobile)
- Clean and reusable component structure
- Interactive FAQ section (Accordion behavior)
- Custom-built slider without external libraries
- Well-structured and maintainable CSS

---

🧩 Project Sections

- Hero Section
- Benefits Section
- Testimonials Slider
- Frequently Asked Questions (FAQ)
- Navigation Cards Section
- Footer Section

---

⚙️ What I Focused On

- Avoiding the use of any external libraries
- Converting fixed layouts into responsive layouts
- Maintaining design accuracy based on the provided UI
- Avoiding unnecessary complexity in logic
- Building components in a clean and scalable way
